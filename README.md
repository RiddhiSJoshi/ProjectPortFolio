# Riddhi Joshi - Developer Portfolio

A responsive personal portfolio website built with HTML5 and CSS3 to showcase my professional profile, technical skills, experience, education, certifications, and development projects.

## Overview

This project is designed as a multi-page developer portfolio:

- `index.html` — Main portfolio/home page
- `Resume.html` — Detailed resume page
- `Resume.css` — Shared stylesheet
- `Images/` — Portfolio images and background assets

The portfolio focuses on clean structure, responsive layouts, reusable CSS classes, and modern UI styling without relying on a frontend framework for the portfolio itself.

## Getting Started

No build tool or package installation is required for the basic portfolio.

### 1. Clone the repository

```bash
git clone <your-github-repository-url>
```

### 2. Open the project

Navigate to the project directory:

```bash
cd Portfolio
```

### 3. Run the portfolio

You can open `index.html` directly in a browser.

For a better development experience, use the **Live Server** extension in Visual Studio Code.

## Customization

Before publishing the portfolio, update the following:

1. Replace the profile image in `Images/developer.jpeg`.
2. Update the email address in `index.html` and `Resume.html`.
3. Replace the LinkedIn URL with your LinkedIn profile.
4. Replace the GitHub URL with your GitHub profile.
5. Update project links if live project URLs are available.
6. Update experience dates/details when your resume changes.
7. Add a downloadable PDF resume if desired.
